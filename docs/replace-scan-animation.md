# Replace In File 扫描动画功能

## 功能说明

当 `replace_in_file` 工具处于 `partial` 状态时（即正在接收参数但尚未完成），系统会：

1. **自动打开目标文件** - 在编辑器中打开要修改的文件
2. **显示扫描动画** - 从文件顶部到底部执行扫描动画
3. **使用浅绿色高亮** - 扫描过程中使用浅绿色背景标识
4. **真正修改时显示 diff** - 当文件实际被修改时，显示标准的 diff view

## 视觉效果

### 扫描阶段（partial 状态）
- **当前扫描行**: 浅绿色背景 `rgba(144, 238, 144, 0.3)`
- **已扫描区域**: 更淡的绿色背景 `rgba(144, 238, 144, 0.1)`
- **扫描速度**: 30ms/行（可调整）

### 修改阶段（非 partial 状态）
- 扫描动画停止
- 显示标准的 diff view，展示原始内容和修改后内容的对比

## 技术实现

### 核心文件

1. **ScanAnimationController.ts** - 扫描动画控制器
   - 管理扫描线的移动
   - 控制装饰效果的应用
   - 自动滚动视图跟随扫描进度

2. **toolExecutor.ts** - 工具执行器
   - 监听 `replace_in_file` 的 partial 状态
   - 启动和停止扫描动画
   - 协调文件打开和修改流程

3. **replaceInFile.ts** - 文件替换工具
   - 执行实际的文件内容替换
   - 打开 diff view 显示修改对比

## 使用流程

```
1. AI 开始发送 replace_in_file 命令（partial = true）
   ↓
2. 系统检测到 partial 状态
   ↓
3. 打开目标文件
   ↓
4. 启动扫描动画（浅绿色，从上到下）
   ↓
5. AI 完成命令发送（partial = false）
   ↓
6. 停止扫描动画
   ↓
7. 执行文件替换
   ↓
8. 显示 diff view（标准颜色）
```

## 可调整参数

在 `toolExecutor.ts` 中可以调整扫描速度：

```typescript
scanAnimationController.start(30); // 30ms 每行
```

- 更小的值 = 更快的扫描速度
- 更大的值 = 更慢的扫描速度
- 推荐范围: 20-100ms

## 注意事项

- 扫描动画会自动跟随当前扫描行滚动视图
- 如果文件很大，扫描动画会持续到文件末尾
- 扫描动画在文件实际修改前会自动停止
- 支持相对路径和绝对路径的文件定位
